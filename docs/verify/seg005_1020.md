## 1028:0000 GenerateWorldMap: PASS

Compared [L]: listing 0000..0590 and the four jump tables 0591..05E6 with generated lines 13-646.
That covers 48 call sites, 35 conditional branches (including `loop` 00BA) and 4 jump tables:
02B8 (8 entries), 0385 (9), 0423 (12) and 04F0 (14), with every case target, shared tail and
empty case. It also covers 7 store sites: 0017, 0036, 0042, 0083/0088, 00B7, 0571, 0582.

* **Control flow:**
  * the 0054 EARTH test;
  * the 013A signed `jg` do-while;
  * pass 2: `jge 0x31/0x4F`, the 01D6/01DC mask 6|9, and the conditional 0214/021B `dec di` /
    `dec y` inside the y loop;
  * pass 3: the compare chain 0/1/2/default and the unsigned band switch (`cmp bx,7; ja`);
  * pass 4 sweeps:
    * 0351/03EF `jle`, 035C/03FA `jle 0`, 0467 `or di,di; jl`;
    * first-sweep cases 6/7/0xC/0xD/0xE;
    * second-sweep cases 0xE/6/0xA and the 0xD->3->0xC fall-through;
  * erosion: parity 048C, and cases 2, 3, 6/7, 0xA, 0xB, 0xC/0xF, 0xD, 0xE;
  * the 0543 `jle`.
* **Arithmetic:**
  * `shl 3; add 0x10; imul 0x28` and `inc; imul 0x320` are W16-wrapped;
  * inline abs is `(v<0)?W16(0-v):v`, so abs(-32768) = -32768;
  * `idiv` by 6 is IDIV16;
  * `cwd; sub; sar 1` is IDIV16(lat,2): same value, and no fault is possible;
  * the EARTH bytes `sub al,0xA` wrap mod 256.
* **Register model:**
  * DI = x (REG_DI_I16) covers all 11 DI writes.
  * SI is written only by the EARTH loop (00AD, 00B9; G1 fixed).
  * Random path: callees save the caller's SI (BeginWorldCreation has SI = 4 after 1108:020A).
    They save the caller's DI until 0160, then x.
  * EARTH path: DisposPtr and GR_PicRead save the caller's SI (before 00AD).
    FillScreenBufferRect (055C) and the LabelBodiesAndFinalizeMap prolog save 0xFA00.
* **Byte push 044A:** see G2 (fixed).
* **Stack residency:** earthPicPort (bp-0x50) is resident because its address is taken
  (FR_PTR(bp,-80)). lpPicBits and the scalars are C variables, each written before it is read on
  every path: erosion iteration 0 is even, so x/y are set before the first odd neighbour step. No
  UNINIT read.

Findings:

  The listing paths are Hills 043C -> 0462, Swamp 0462, Mountains 045E -> 0462.
  * Hills misses step 0462, and Swamp and Mountains run a spurious 043C step.
  * Statements, pushes and the emulated stack are right. Only the vm_site attribution and the

  * Root cause [T]: the markers follow the recovered C's case order (src/c lines 369-374).
* **G4. NOTE (unchanged).** The 00AC `push ds` / 00BC `pop ds` pair is emitted before the loop
