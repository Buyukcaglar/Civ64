## 1200:00A8 AnimatePortPalette: PASS

Compared:

* **Frame.** [L][D] Prolog 00A8..00B5 (`... sub sp,4; push si`), epilogue 0101..0107 (`pop si; pop
  cx; pop cx; pop ds; pop bp; dec bp; retf`) against `FR_AnimatePortPalette` (civ_frames.c:805):
  argbytes 10 (port 4, hColorTable 2, firstIndex 2, count 2), popbytes 0, FR_WIN_FAR, far_ret 1,
  push_ds 1, nregs 1 {SI}, locals 4, popcx 1. Match. [G] Lines 23-26: `CX_CHK32` +6, `CX_CHK16` +0xA,
  and `CX_CHK8` for the byte parameters at +0xC/+0xE (only the low byte of those words is defined).
* **Register parameter (fix 3).** [L][G][T] 00B6 `mov si,[bp+hColorTable]` is in the entry block, the
  slot is read nowhere else and SI is not written again, so the binding `REG_SI_U16 = hColorTable;
  /* 1200:00B6 */` (line 28) is correct; every later use reads `REG_SI_U16` (lines 30, 31, 45-47). The
  listing header also names `register si = hColorTable`.
* **Lock.** [L][G] 00B9 `push si`, 00BA `call far KERNEL.GlobalLock`, ra 0x120000BF: lines 30-31
  (pascal API, no `add sp`, no `stk_drop`). 00BF/00C2 store DX:AX at [bp-4]/[bp-6]: `lpEntries` (line
  32), a C variable (see residency).
* **Byte-to-word arguments.** [L][G] 00C5..00D6 push three words built with `mov al,byte; mov ah,0;
  push ax`: zero-extended firstIndex, count, firstIndex. Lines 34-39 push `(int16_t)(uint8_t)` of the
  same parameters, so the high bytes are 0 as in the listing (these are byte values widened to `int`
  for the callee, not byte arguments).
* **Call.** [L][G] 00D7/00DA push the high and low word of `lpEntries` (lines 40-41); 00DD `call far
  SetGodPaletteEntries`, ra 0x120000E2 (line 42). The C arguments (lpEntries, srcStart = firstIndex,
  count, dstStart = firstIndex) match the pushed words in cdecl order (dstStart 00CA first, src
  last). 00E2 `add sp,0xa` is `stk_drop(10u)` (line 43).
* **Unlock.** [L][G] 00E5 `or si,si; je 00EF`, 00E9 `push si`, 00EA `call far KERNEL.GlobalUnlock`, ra
  0x120000EF: lines 45-48. GlobalLock is called even when hColorTable is 0, as in the listing.
* **Transient push.** [L][G] 00EF `les bx,[bp+port]`, 00F5 `push es` (the selector of `port`),
  00F6..00F8 load `g_hGodPalette` through ES = DGROUP, 00FC `pop es`, 00FD store at `port+6`. Lines
  50-53 push the high word of the argument slot [bp+6] at 00F5, pop it at 00FC (same SP as the
  listing; `DESIGN.md` 3.4 transient pushes) and store `g_hGodPalette` (1420:9966) at
  `port->hPalette` (+6).
* **Residency.** [L][F] `lpEntries` ([bp-6], 4 bytes) is written at 00BF/00C2 before its reads at
  00D7/00DA, its address is never taken, it is not indexed and the slot has one name; no `DESIGN.md`
  item (e) entry names it. A C variable is correct (5.2 item 2), except for the epilogue read noted
  in N1.
* **Register model.** [L] At 00DD SI = hColorTable in both the listing and the port, so any frame of
  SetGodPaletteEntries that saves SI saves the same word.
* **Dispatch, helpers, x87, divisions.** [L] None.
* **UNINIT / BUG / OOB.** [F] No findings site in 1200:00A8..0107 and no citation of the function; no
  8.2 or `DESIGN.md` 3.4 row; `gen/annot.py` has no entry. The unit carries no BUG/OOB/UNINIT comment,
  which is correct.
* **Registers after the return.** [L] The listing leaves AX = `g_hGodPalette` (00F8), DX as
  GlobalUnlock/SetGodPaletteEntries left it, and CX as in N1; the port models none of them (the
  function is `void`). [S] 3 call instructions: WinMain 1008:023D and AdvanceMovie 10B0:1144 reach
  later calls without reading AX, CX or DX; AnimatePaletteFromGrPort 1200:0136 returns (`void`,
  1200:013F) with all of them live, and its 26 call sites read none of them
  (`verify/seg064_11F8.md`, AnimatePaletteFromGrPort, [S]). No `ret_ax`/`ret_ah` annotation is needed.
* [R] Lines 378-391 agree.

Findings:

* **NOTE N1** (1200:0102/0103; `fr_leave` after line 53). The epilogue discards the locals with two
  `pop cx`, leaving CX = [bp-4], the high word of `lpEntries` (the selector GlobalLock returned). The
  port keeps `lpEntries` as a C variable and never writes [bp-4], so `fr_leave` sets `cpu.cx` to the
  stale slot word (`DESIGN.md` 3.4 "pop cx teardown"). [S] No caller reads CX after the return (see
  above), so no residency is required under 5.2 item 2(e). No defect.
