* **N1 NOTE (reproduced).** [F][L][G] `oldOwner` (bp+8) is never read (findings.md l.1953, section 14, not a parsed bug section; no comment due). The port reads it only in the checked-build `CX_CHK16` (l.20).
* **N2 NOTE (stack words, for verify/seg053_11A0_r.md T1).** [S][L][C] CaptureCity calls StartCivilWar (1038:0116 push, 0119) and FindMostCentralCity (1038:0135 push, 0138) from the same SP with one argument word, so both frames have the same BP (B). FindMostCentralCity's MapDistance call (0F6F, Windows far frame) writes the saved `BP+1` = B+1 at B-0x1A, the slot of StartCivilWar's uninitialised `cityIndex` (bp-0x1A). A capital capture that took the FindMostCentralCity path therefore leaves B+1 there unless a later frame overwrites it; that word is written by `fr_enter` (modelled). Candidate last writer only; not traced further.
* **N3 NOTE (general, DESIGN.md 3.4).** [G] The non-resident locals sum/bestCity/minSum are C variables, so the emulated stack bytes B-8..B-3 keep stale words where the original leaves the last sum/bestCity/minSum. Only a later class (a) uninitialised read at those addresses could observe it (DESIGN.md 3.4 "Open (phase 3)").
