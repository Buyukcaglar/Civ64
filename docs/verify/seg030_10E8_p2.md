## Findings

* **NOTE N1** (CheckCivilizationDestroyed; teardown 1D40..1D43; l.18-19, 120). popcx=1: the final `pop cx` leaves CX = the word at bp-4 (`y`). The port keeps `y`/`keepMask` as C variables, so `cpu.cx` is stale (DESIGN.md 3.4 "pop cx teardown"). [S] None of the four callers reads CX before writing it:
  * 1030:0B47 jumps to 002E: `xor ax`...;
  * 1038:0831 pops;
  * 1078:0DEA → 0DED `mov ax`;
  * 11F0:27B6 `mov ax`.
  No effect.
* **NOTE N2** (CheckCivilizationDestroyed; l.14). G7's defect is in FoundCity (1040:0309: the Palace test ignores freed slots). This function is cited only as context: AI civs that lose their last city are removed here, which is why the human and respawned civs are the affected cases. The function-level comment follows the rule because the citation is not excluded. The precedent is `verify/seg020_1098_p1.md` N2 (H63, GR_DialogClose). An `EXCLUDE` entry for (`G7`, `10E8:1B97`) would drop it if the maintainers prefer. Comment only.
* **NOTE N3** (BalanceStartPositions; 1DDF..1E00; l.201-203). `startsPerBody[startBody[civ]]++` indexes the 16-word array with GetBodyId's result, unchecked. The arrays are resident and use `va_ix`, so any out-of-range id is reproduced byte for byte (it lands in `startBody`/locals above). findings.md has no entry for it; latent.
* **NOTE N4** (BalanceStartPositions; l.128-184). The scalar locals are C variables, so their frame bytes are not written: rivalFarMask, bestCiv, ocean/grassland/riverCount, terrain, distance, nearestRival, debugRowY ("written, never read", l.184), maxScore, unitSlot and civ. None has its address taken, and the epilogue is `lea sp`, so nothing reads them. No 5.2 item 2 reason applies.
