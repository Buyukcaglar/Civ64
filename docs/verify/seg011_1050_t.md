   COLORREF/LPARAM.
2. **Register mirrors.** PaintRandomRadio SI = hdc (000F), DI = the dot offset of the three

   DI = hwnd (0506), SI = hdc (0509); the four window procedures SI = hwnd and DI = the
   SetWindowWord flag of WM_CREATE. [L] Every parameter load is in the entry block, the listing
   never reads those parameter slots again and never writes SI (or PaintRandomStatic's DI) later:
   the bindings follow brief fix 3. No `regs` annotations.

   (1058:0086, 00A6, 0555, 075C, 0789, 07AE, 07D6, 08DA, 0A99, 0ACD) are evaluated in listing order,

   075C: IsWindowEnabled (815) before PaintRandomRadio (820).

   DX, AX and popped as EAX in the four painters (body pushes plus `stk_drop`, values `t >> 16` and
   `t & 0xFFFF`).

   and source pushed as `ss`/offset pairs, `mov cx,8` ↔ size `8u`; SCOPY@ pops its own 8 bytes, and
   the listing has no `add sp` after either call.
7. **Statement markers, pointer differences.** Markers carry listing addresses. No pointer
   difference.
8. **x87, divisions.** [L][G] No x87. The signed halvings `cwd; sub ax,dx; sar ax,1` (round toward

9. **Code pointers given to Windows.** [D] The four window procedures are `DC_WNDPROC` entries with
