### Findings

* **T1 (TRANSLATOR, verifier's find, rule 6.6): the WM_TIMER path pushes the unwritten local
  hdcPaint [bp-4] at 1208:01AA; hdcPaint is a zero-initialised C variable, not stack-resident, and
  there is no DESIGN.md 3.4 row, no `/* UNINIT */` marker and no FIDELITY entry.** [L][G][R][F][C]
  The only write of [bp-4] is `mov [bp+hdcPaint],ax` after BeginPaint at 02D8 (WM_PAINT path); the
  WM_TIMER path (019D..01B2) reaches `push word ptr [bp+hdcPaint]` (01AA) without a write in this
  frame (findings H5 documents the read; the showfunc annotation at 019D says "uninitialised but
  ignored by the callee"). The generated C declares `uint16_t hdcPaint = 0;` (l.22) and pushes it at
  l.171, so the port pushes 0 where the original pushes the stale stack word. The last writers of
  bp-4 in a WdwMapProc frame are earlier frames at the same depth under the Windows message dispatch
  (DispatchMessage/SendMessage and other w16/API frames, or an earlier WdwMapProc WM_PAINT at the
  same BP), so class (b). Impact is limited to the emulated stack word: CyclePaletteColors takes the
  word as `hdcUnused` and does not read it (H5: "The callee takes no parameter"). Needed (rule 6.6;
  precedent DESIGN.md rows 11E0:00F6 and 1208:1938, `verify/seg007_1030_p1.part4.md` T2): hdcPaint
  stack-resident (5.2 item 2(b)), a DESIGN.md 3.4 row with the last writers, `/* UNINIT: DESIGN.md
  3.4 WdwMapProc hdcPaint, class b */` at 01AA and a FIDELITY entry stating there is no observable
  outcome. Recovered C (l.514, 569-571) matches the listing (no RECOVERY).
